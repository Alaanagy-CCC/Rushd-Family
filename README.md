# رُشد أبناء

صفحة متابعة يومية للأبناء: التحديات، والواجبات، والمصروف، والتقارير. نسخة من «رُشد العائلي».

- البيانات محلية على كل جوال (localStorage)، ولا خادم ولا مزامنة.
- التبادل مع وليّ الأمر بملفات صيغة `rushd-family` إصدار 1، ويعاين الابن كل ملف ويقبله أو يرفضه.
- لا يحتوي المستودع على أي بيانات شخصية.

الرابط: https://alaanagy-ccc.github.io/Rushd-Family/

## النسخ
- رُشد أبناء: https://alaanagy-ccc.github.io/Rushd-Family/
- رُشد زوجة: https://alaanagy-ccc.github.io/Rushd-Family/zawja/

النواة مشتركة في `rushd.js` و`rushd.css`، وكل نسخة تختار وحداتها عبر `window.RUSHD_EDITION`. لكل نسخة مفتاح تخزين مستقل.
